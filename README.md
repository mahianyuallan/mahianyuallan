# Allan Mwenja Mahianyu

**Software Engineer: Payments & AI** · Nairobi, Kenya · [allanmwenja.com](https://www.allanmwenja.com/)

I'm a backend-focused software engineer. I build APIs, payment systems and AI agents, and I care most about the parts that can't be wrong: payment verification, exactly-once fulfilment, reconciliation, and controls on what an AI agent is allowed to do. The rule I design around is to fail closed. If a payment doesn't verify, it isn't fulfilled; if an agent action isn't approved, it doesn't run; if a model's output doesn't validate, a person reviews it.

## What I work on

- **Backend engineering and API development:** REST APIs with clear contracts (OpenAPI), authentication, role-based and object-level authorization, rate limiting and tests.
- **Payment systems:** payment reconciliation (including M-Pesa), card payment gateway integration through certification testing, and idempotent, auditable payment flows.
- **AI engineering, agents and automation:** LLM pipelines with deterministic guardrails, tool gateways for agents (MCP), provider adapters, prompt evaluation and workflow automation.
- **System architecture and full-stack development:** stateless services, caching, provider integrations and React/TypeScript frontends on top.
